Bus Pass System

The Bus Pass System is a full-stack web application developed to digitize and automate the process of issuing and managing bus passes. The platform enables users to apply for new passes, renew existing passes, and monitor application status online, while administrators can manage approvals, routes, and user records through a centralized dashboard.

Features
Online bus pass application
Pass renewal system
Admin approval/rejection panel
User authentication and authorization
Route and fare management
Digital pass generation
Application status tracking
Responsive user interface

Tech Stack
Frontend: HTML, CSS, JavaScript 
Backend:  Python
Database: MySQL
